# Madeirarte Móveis Rústicos

Website institucional de alto padrão da **Madeirarte Móveis Rústicos**, especializada na fabricação artesanal de móveis exclusivos em **Madeira de Demolição (Peroba Rosa)** para atacado e varejo.

## 🌲 Destaques do Projeto

- **Design Premium & Responsivo:** Identidade visual sofisticada com tons amadeirados nobres, tipografia refinada e layout 100% responsivo para desktop, tablets e smartphones.
- **Seção Hero Imersiva:** Apresentação da marca com slogan oficial, botão para orçamento rápido e logo integrada.
- **Quem Somos:** Destaque para os mais de 20 anos de tradição e marcenaria artesanal com Madeira de Demolição.
- **Serviços Especializados:** Ícones 3D detalhados ilustrando Fabricação Própria, Venda no Atacado, Venda no Varejo e Peças Sob Medida.
- **Coleção em Destaque:** Filtros dinâmicos por categoria (Mesas, Cadeiras, Aparadores, Outros) com fotos de alta qualidade e botão para solicitação direta de orçamento.
- **Nossos Trabalhos (Instagram Feed):** Carrossel integrado com publicações oficiais da marcenaria no Instagram.
- **Diferenciais & Depoimentos:** Carrossel interativo de avaliações de clientes com setas laterais e auto-scroll.
- **Perguntas Frequentes (FAQ):** Acordeão interativo para esclarecimento de dúvidas sobre orçamentos personalizados e madeira nobre.
- **Conformidade LGPD:** Páginas completas de Política de Privacidade e Termos de Uso com banner interativo de cookies.
- **Botões Flutuantes:** Acesso direto via WhatsApp e Instagram no canto inferior direito da tela.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Layout moderno com Flexbox, CSS Grid, variáveis customizadas, transições fluidas e animações.
- **JavaScript (Vanilla):** Navegação dinâmica, carrosséis, acordeão de FAQ, filtros de produtos, banner LGPD e integração com API do WhatsApp.
- **Node.js:** Servidor local leve para testes e desenvolvimento.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/cristianealvesfr-hash/madeiramoveis.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd madeiramoveis
   ```

3. Inicie o servidor local:
   ```bash
   node server.js
   ```

4. Abra no seu navegador:
   ```
   http://localhost:3000
   ```
